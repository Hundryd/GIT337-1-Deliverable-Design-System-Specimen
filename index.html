Design System Specimen

Small publication foundation

Reusable patterns for a calm, useful reading experience

This specimen establishes the visual grammar for future modules: foundations, tokens, type, interactions, surfaces, and form controls. It is intended as documentation, not a finished marketing home page.

S1

Foundation and reset

The reset is intentionally selective: it corrects layout traps and cross-browser quirks without stripping accessibility cues or user-agent semantics. This keeps native form controls, focus rings, and semantic headings available to future modules.

  • box-sizing: border-box prevents width math drift on nested panels.
  • body margin reset removes default spacing so layout can be controlled.
  • img/svg max-width: 100% preserves responsive media while preventing overflow.
  • button/input/select font inherit keeps all controls aligned with the type system.

Reset usage note

We intentionally avoid a broad “all: unset” or blanket list reset because it removes meaningful browser affordances such as the default outline, table semantics, and form input behavior. This design system favors a compact foundation that supports reading, usability, and future component composition.

S3

Typography

Byline · January 2026

Headings balance editorial clarity with accessible rhythm

Body copy uses generous line height and a narrow measure to support reading comfort. A default fallback stack keeps text legible even when the preferred family is blocked or unavailable.

Source Sans 3 and Source Serif 4 are used as the preferred families; they are open source and distributed under the SIL Open Font License. When the preferred font fails, the browser falls back to local system serif and sans-serif stacks without breaking the layout.

  • Editorial headings remain high-contrast and confident.
  • Lists stay readable and easy to scan.
  • Inline code uses a monospaced fallback stack for technical notes.
